# MePwned

Interactive Python assessment suite with a terminal launcher (`mepwned.py`) and independent modules. The launcher displays version 1.0.

See [the technical handoff](HANDOFF.md) for architecture, the complete file inventory, local review setup, data handling, known limitations, verification results, and the ownership checklist.

Several modules modify accounts, academic or financial records, send notifications, or contain remote-command payload logic. Use an isolated environment with synthetic data for maintenance testing. Existing files in `dumps/` must be reviewed by their data owner before transfer.

Documentation is based on static source inspection dated 30 September 2026. Live behavior and target compatibility have not been verified.
